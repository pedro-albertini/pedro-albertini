### 💼 Sobre mim

Sou estudante de **Desenvolvimento de Software Multiplataforma na FATEC Diadema** (previsão de conclusão: 06/2027) e técnico em **Análise e Desenvolvimento de Sistemas** pela ETEC JK.

Fiz estágio em **DevSecOps na Compass UOL** (jul/2025 – dez/2025), numa trilha prática de Cloud, automação e segurança: AWS, CI/CD com GitHub Actions, GitOps com ArgoCD, containers com Docker e observabilidade em Linux com práticas de FinOps.

Gosto de automatizar o que é repetitivo e de entender como a aplicação chega até produção. Estou em busca de **estágio ou vaga júnior** em Cloud, DevOps, DevSecOps ou desenvolvimento.
